# pyRevit AI 🚀

pyRevit AI to proste i intuicyjne narzędzie stworzone z myślą o projektantach instalacji HVAC, wykorzystujące sztuczną inteligencję (AI), duże modele językowe (LLM) oraz pyRevit do usprawnienia codziennych zadań projektowych w środowisku Autodesk Revit.

## 🎯 Cel projektu

Naszym celem jest ułatwienie i przyspieszenie procesu projektowania instalacji HVAC poprzez automatyzację rutynowych zadań, weryfikację poprawności projektów oraz dostarczanie inteligentnych rekomendacji bezpośrednio w Revit.

## 🛠️ Technologie
- **pyRevit** – platforma umożliwiająca tworzenie skryptów i narzędzi do Autodesk Revit w języku Python.
- **AI & LLM** – wykorzystanie dużych modeli językowych do analizy danych projektowych, wykrywania błędów oraz automatycznego generowania rekomendacji.

## 📚 Jak korzystać?

Po instalacji narzędzie będzie dostępne jako panel w pyRevit. Możesz uruchomić je bezpośrednio z poziomu interfejsu użytkownika Revita:

- Wybierz odpowiedni model HVAC w Revit.
- Uruchom skrypt, aby przeanalizować instalację.
- Otrzymaj automatyczne rekomendacje, które możesz zastosować bezpośrednio w projekcie.
